## geekbench7-linux 1.0.0

First stable release of **Geekbench 7 for Linux (unofficial)**.

- Wrapper-only packages: deb, rpm, Arch, AppImage, Flatpak, snap, tarball
- Downloads official Geekbench 7 from `cdn.geekbench.com` (amd64 + arm64)
- Never redistributes or patches Geekbench
- SonarQube Cloud analysis with ≥90% coverage gate

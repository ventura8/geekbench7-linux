## geekbench7-linux 1.0.0

First stable release of **Geekbench 7 for Linux (unofficial)**.

- Wrapper-only packages: deb, rpm, Arch, AppImage, Flatpak, snap, tarball
- **amd64**, **arm64**, and **riscv64** package builds where applicable
- Downloads official Geekbench 7 from `cdn.geekbench.com`
  - amd64: `Geekbench-*-Linux.tar.gz`
  - arm64: `Geekbench-*-LinuxARMPreview.tar.gz` ([preview](https://www.geekbench.com/preview/))
  - riscv64: `Geekbench-*-LinuxRISCVPreview.tar.gz` ([preview](https://www.geekbench.com/preview/))
- Never redistributes or patches Geekbench
- SonarQube Cloud analysis with ≥90% coverage gate

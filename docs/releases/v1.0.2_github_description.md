## geekbench7-linux 1.0.2

- **`geekbench7`** is the default way to run Geekbench (passthrough flags)
- **`geekbench7-linux`** is wrapper-only (`setup`, `update`, `doctor`, …)
- **`geekbench7 wrapper …`** reaches the same management commands
- README: badges, one-line installer, clearer packaging docs
- CI dependency bumps (ruff, pytest, yamllint, Actions pins)
